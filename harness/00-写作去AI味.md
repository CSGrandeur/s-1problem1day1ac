# 写作去 AI 味（语言层 · 最高优先级）

> **适用范围**：对话回复、文档、注释说明、用户可见文案、邮件/汇报、博客、讲义、PPT 讲稿等一切由 Agent 产出的中文（及中英混排）自然语言。  
> **优先级**：语言层高于本仓库其他 harness / AGENTS / 风格偏好。与「部署红线」「配置硬编码红线」等**行为红线**并存：行为红线管做什么，本文管怎么说。  
> **来源**：综合公开讨论中可操作的去 AI 味清单（平衡句立靶、表演性套路、符号三件套、名词化等），凝练为可执行规范。

## 0. 总根

AI 味的一大族 = **在表演美德，而不是执行它**：

- 平衡句表演文采
- 拆词表演分析
- 「先说结论」表演条理
- 「问到点子上」表演倾听
- 金句收尾表演深刻

真人写作：分析隐形，只出场结果。

**统一判据**：删掉这句，信息少了吗？没少 → 表演，删。

**铁律（怎么改才安全）**

1. 只改命中风格问题的句子；干净的句子原样不动。
2. 事实 / 数字 / 专有名词 / 引用 一律不动（本文只动语言，不做事实核查）。
3. 绝对词（所有 / 从不 / 唯一 / 首个 / 必须）不擅自删弱，除非确知用错。
4. 拿不准就别动。
5. 代码标识符、API 路径、配置键、表字段名、错误码等**技术字面量**不受「去引号 / 换平实词」约束。

---

## 1. 平衡句与立靶子（最难纠正，优先盯）

人用平衡句是因为内容里**真有**对立；AI 常为结构而造对立。

| 禁用 / 慎用 | 说明 |
|-------------|------|
| 「不是 X，而是 Y」立靶 | X 没人主张过时，等于自造对手衬托 Y。判据：删掉「不是 X」整句意思不变 → 必删。只有 X 真是流行观点时才可先立再破。 |
| 「不仅…而且」「既…又」「一方面…另一方面」 | 能直说就直说；对称/排比能拆就拆。 |
| 「你以为…其实是…」 | 无真实误解前提时删。 |
| 「当 A 还在…时，B 已经…」 | 刻意认知对比，多数空洞。 |
| 「如果说 A，那么 B」 | 限频；非必要不用。 |

直说示例：❌「排第一的不是火箭会不会炸，是马斯克本人」→ ✅「排第一的是马斯克本人」。

---

## 2. 符号与标点（中文三件套）

- **破折号**：限用。只在后面紧跟一句很短的解释时用；别塞长插入语；整段别扎堆。中文默认少用破折号。
- **引号**：能省则省。日常词（消失、变了、增长、风险、影响…）别加引号。只有「非字面义 / 反讽 / 术语首次下定义」才用。
- **顿号**：别滥用顿号堆砌并列概念（「高烈度、不对称的信息战」类）。

---

## 3. 套话、宣告、空转过渡 → 删

**空转过渡**：值得注意的是、需要强调的是、需要指出的是、不可否认的是、众所周知、不难发现、具体来说、进一步而言、与此同时、从某种程度上来说、从本质上来看、在当今快速发展的时代、随着科技的不断发展。

**宣告式**：说到底 / 归根结底 / 先说结论 / 划重点 / 综上所述；「先把 X 说清楚」「先说清楚一件反直觉的事」「话说在前头」「把话说前头」——直接进内容。

**「清楚 / 反直觉」**：少用「说清楚 / 讲清楚 / 彻底搞懂」；「反直觉」只在结论真反直觉且有把握时用。标题/小标题里「先」「必须」「清楚」「反直觉」一律别用。

**自问后别垫宣告**：自问后别接「背后是几股力量 / 原因有三」；直接写要点。别用「还有一个关键地方容易被看漏」——直接说，或只用「另外」。

**「一句话」类禁用**：一句话、就一句话、核心建议只有一句、一句话讲清/总结。

**「先说/先给/先看」宣告**：先说漂亮的一面、先给结论、先看某某——删，直接进内容。

**会议式编号总结禁用**：「三句话。第一句…」「三点。第一点…」——总结连着说。

**对词动手术禁用**：先把 X 这个词拆开 / 拆解 / 解构 / 厘清 / 界定 X 这个概念 / 重新定义 X。宾语应是世界上的事，不是词本身。  
边界：「举个例子 / 打个比方 / 算笔账」可保留。

**对话接话禁用**：这个问题问到点子上了、问得好、这个问题很关键——直接答。

**老规矩 / 仪式化开场禁用**：老规矩咱们…、还是那句话、照例。

**明令禁用短语**：说白了、脊背发凉、后背发凉、掰开揉碎了说、直接给你答案、讲透了、毛骨悚然、值得一提的是；聊天收尾「希望以上内容对你有所帮助」「如果你愿意我可以继续」「如需进一步优化请告诉我」。

## 4. 用词：装饰、酷词、AI 腔、文绉绉

**无意义程度/装饰词 → 删**（删掉断言不变则删）：非常、极其、大大、显著地（非统计义）、关键、核心、至关重要、革命性、全方位。

**人为情绪标签 → 平实**：扎心的真相、残酷的、令人揪心、触目惊心、可怕的是。

**AI 腔词 → 换平实**：赋能、抓手、闭环、链路、维度（非专业义）、底层逻辑、深耕、彰显、保驾护航。

**文学化/比喻/拟人 → 还原**：画卷、基石、灯塔、揭开神秘面纱、踏上…旅程；给无生命物「想要/聪明地/决定」。每段最多一个贴切比喻。「家底」类 → 直说财务情况等。

**被用滥的酷词 → 普通词**：盯（全世界都在盯）→ 关注；狂飙、杀疯了、拉爆、起飞、血洗、屠榜、扎心、硬核 → 平实说幅度。判据：三年前新闻稿不会用、现在满屏都是 → 换。

**「最 X」冗余**：最真相、最硬核、最干脆、最客观、最直接、最一针见血… → 删「最」。真最高级保留（最大的风险）。判据：去掉「最」意思不变 → 删。

**「到底 / 究竟」限频**：一篇最多 1–2 处；其余改成「是什么样」「发生了什么」。

**生僻/文绉绉 → 简**：旨在→为了、藉由→通过、诸如→比如、予以→给、较之→比。（专业术语保留。）

**「以……」后置目的句**：限频。「以实现 / 以确保 / 以完成」每段至多偶尔一次；能改成「为了…」或拆成两句就拆。

**「这意味着…」**：英文 which means 痕迹，中文能直说就直说。

**「通常」**：非严谨科普/论文语境少用；别每段都挂官方味限定。

**首先…其次…最后…**：能不用序号就不用；真要分点，用短标题或自然段，别念纪要。

## 5. 动词优先，去名词化（常被忽略）

名词化 = 把动作冻成抽象名词，是 AI 腔和翻译腔大来源。

- 杀「弱动词+名词」：「进行了分析」→「分析了」；「做出决定」→「决定」；「对 X 造成影响」→「影响了 X」；「实现增长」→「涨了」。
- 状态/判断 → 动作/感官（叙事尤其）：「他很紧张」→「他攥着杯子，指节发白」。
- 形容词/副词堆叠 → 一个准动词：「快速地走过去」→「冲过去」。

**红线（别过度）**：专业术语本就是名词（磷酸化、凋亡…）别碰；论文「这一抑制导致…」类衔接可留；别把每句都改成短促动作。

**翻译腔**：少用「她是漂亮的」式西文骨架；优先「她很漂亮」类中文习惯。

## 6. 语气与信息密度

- 商量而非指令：要/必须/不要/务必（非真正红线处）→ 不妨/可以/最好/建议。真正紧迫仍直说「尽快」。
- 居高临下（「很多人犯的错是…」）→ 平等（「有一种想法其实挺常见：…」）。
- 保留必要模糊限定（可能/多数/一般），不删成绝对化。
- 平实、不煽情、不制造焦虑；也不降成无信息口水。
- **信息密度**：少正确的空话。能写具体做法、具体例子就写；覆盖全面但无可执行信息 = 失败。
- **别反复换花样说同一句**：同一信息只出现一次，后续用指代。

---

## 7. 结构与段落

- 开头别预告结构，直接进内容。
- 段首/句式别连续雷同；长短句可交错，拿不准就别刻意整。
- 少用「Markdown 表演」：无意义加粗、清单套清单、表格塞正确的废话。表格只在真有对照关系时用。
- 对话/口播：接话表扬删掉。口播可适度「哎/啊/呢/嘛/你看/对吧」（一段两三处）；书面稿不加。叹词写「哎/唉」，不写「欸」。

---

## 8. 英文写作（附加）

少堆多音节书面词撑场面；慎用已被标成模型口癖的词（如早期 delve / tapestry 等，以当下语感为准）。破折号同样限用。直接陈述，少 not A but B 立靶。

## 9. 自检清单（交付前扫一眼）

- [ ] 有没有「不是 A 而是 B」且 A 是自造靶子？
- [ ] 破折号 / 多余引号 / 顿号堆砌是否扎堆？
- [ ] 有没有空转过渡、先说清楚、一句话总结、问得好？
- [ ] 装饰词、AI 腔词、酷词、冗余「最」是否可删？
- [ ] 弱动词+名词能否还原成动词？
- [ ] 删掉某句后信息是否不变？（不变则删）
- [ ] 同一意思是否换花样说了两遍？
